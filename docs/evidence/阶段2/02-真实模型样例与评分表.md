# 真实模型样例与评分表（定 D2/D3）

> 用真实 DeepSeek 对 5 份示例转写生成的练后反馈。请产品经理逐条打分（每维度 1–3 分），并标出"不能接受"的样例。

## 样例 1：带货·弹幕应答（价格追问未回应）
- 问题①【直播应对】12–18s「价格方面大家放心，很实惠的。」→ 只用"很实惠"笼统带过，未回应价格追问 → 建议直接报价/给区间或引导看小黄车。
- 问题②【内容质量】18–24s「效果嘛，反正就是好用，大家赶紧下单。」→ 未结合商品资料（350ml、USB充电）说效果 → 建议围绕容量与充电展开。
- 优先：①②

## 样例 2：带货·开场（开场平淡）
- 问题①【表达表现】0–5s「大家好，今天给大家介绍一个产品。」→ 未点明主题与利益点 → 建议开场点出场景。
- 问题②【内容质量】5–15s「就是这个清洁喷雾。大家可以看看，需要的可以买。」→ 全程无产品信息 → 建议补具体卖点/场景。
- 问题③【直播应对】10–15s「需要的可以买。」→ 无互动钩子 → 建议加留人话术。
- 优先：①②

## 样例 3：娱乐互动·冷场处理（互动不足）
- 问题①【直播应对】6–14s「呃，也不知道聊什么。」→ 冷场把话题抛给观众，未主动提供内容 → 建议准备素材主动抛话题。
- 问题②【表达表现】14–22s「没有的话我就随便讲讲。」→ 消极预设削弱邀请 → 建议改开放式提问。
- 问题③【内容质量】0–6s「大家好啊，今天来聊聊天。」→ 开场未点"周末趣事"主题 → 建议开场给具体引子。
- 优先：①②

## 样例 4：知识内容·通俗度（术语太多）
- 问题①【内容质量】6–12s「它的数学本质是指数增长模型。」→ 术语未通俗解释 → 建议换生活化说法。
- 问题②【内容质量】12–20s「用年化收益率和计息周期来推导终值公式。」→ 连续专业概念无举例 → 建议用具体数字举例。
- 优先：①②

## 样例 5：知识内容·依据（结论无依据）
- 问题①【内容质量】0–6s「睡眠不足会严重影响健康。」→ 只有结论无依据 → 建议补研究/数据。
- 问题②【内容质量】6–12s「这个大家都知道的。」→ 用"大家都知道"回避论证 → 建议替换为具体依据。
- 问题③【直播应对】12–18s「所以一定要早睡，别熬夜。」→ 建议前未给依据 → 建议先说依据再给建议。
- 优先：①②
