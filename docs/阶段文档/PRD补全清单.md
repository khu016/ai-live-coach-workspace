# PRD 补全清单

> 产品：AI 主播陪练（PRD v0.1）。本清单是阶段 0 体检产出：缺口分"必须问"与"可默认"两类。必须问一次不超过 5 个，每个可回复"按推荐"。

## 必须问（本轮 5 个，已全部确认：均选 A，2026-09-18）

### 问题 1：隐私与合规边界（音视频含人脸、声音）
- 为什么重要：录像和转写含人脸、声音等敏感个人信息，决定数据能否出境、能否交给第三方模型、能否用于训练，直接影响安全与合规。
- 选项：A 全部境内处理，只发国内厂商，不用于训练；B 境内处理 + 允许用脱敏数据优化；C 暂不设限，上线前再定。
- 推荐：A。直播行业数据敏感，先按最严标准跑通闭环，后续要放宽再单独确认。
- 不选的后果：选了 B/C，后续若合规不通过要返工改存储与模型链路，成本更高。

### 问题 2：模型厂商与成本上限
- 为什么重要：本产品有三类 AI 能力（语音转写 ASR、画面检测、LLM 生成弹幕与反馈），成本和合规取决于选谁，PRD 未指定。
- 选项：A 国内厂商统一接口（转写用国内 ASR + DeepSeek/通义/智谱等 LLM），单场训练成本 ≤ X 元、开发期每月 ≤ 100 元；B 只定厂商不定上限；C 由我推荐后再定。
- 推荐：A（X 建议先按"单场 ≤ 1 元、开发期每月 ≤ 100 元"占位，参照其他项目惯例；具体费率我到技术适配阶段核查官方价后给你确认）。
- 不选的后果：不定上限，长任务可能产生意外费用；不指定国内厂商，可能触发数据出境合规问题。

### 问题 3：机构功能第一版做到什么深度
- 为什么重要：PRD 把机构任务（F11）、机构内容管理（F13）列为 P0，但 1.2 又说"机构培训效率暂不作为首要成功标准"，2.2 排除复杂编辑器——边界需要你拍板，直接影响交付范围。
- 选项：A 机构做最小闭环（负责人分配训练 → 查看录像/成长记录 → 带教老师人工"通过/不通过"），复杂场景编辑器不做；B 机构功能也做完整版；C 第一版先不做机构，只做个人主播。
- 推荐：A。保住机构"能看到、能考核"的最小价值，不铺开复杂编辑器，聚焦第一版首要验证目标（个人主播反复练习、看到进步）。
- 不选的后果：选 B 会显著加大第一版工作量；选 C 会砍掉机构用户的首轮试用入口。

### 问题 4：机构任务录像的权限与删除规则
- 为什么重要：PRD 6.2/F10 自己强调"主播退出机构后的录像权限、机构记录删除规则待确认，确定前不能用权限含糊的默认共享实现"，这是隐私红线。
- 选项：A 机构任务录像由机构负责人/获授权带教老师查看，删除由机构方或主播本人发起、按身份校验；主播退出机构后录像归属机构、主播只保留自己的个人练习；B 全部由主播掌控；C 退出机构即删除机构任务录像。
- 推荐：A。兼顾机构考核需要与主播个人数据主权，删除走明确的后端身份校验。
- 不选的后果：选 B 机构拿不到成员录像无法考核；选 C 主播一退出历史考核记录丢失，机构无法追溯。

### 问题 5：未成年人限制与年龄确认
- 为什么重要：直播训练涉及主播出镜，未成年代言/出镜有监管要求，决定是否要加年龄门槛（影响安全与目标用户范围）。
- 选项：A 限制 18 岁以上使用，创建账号时做年龄确认；B 不限制但做内容合规提示；C 先不做任何限制。
- 推荐：A。参照本工具包其他项目的年龄确认做法，成本低、合规风险小。
- 不选的后果：选 B/C，若涉未成年出镜，上线可能被下架或追责。

## 可默认（已用默认值填上，待产品经理确认一次）

| 缺口 | 默认值 | 理由 |
| --- | --- | --- |
| 登录方式 | 邮箱验证码登录，预留手机号/第三方接口 | 账号体系（个人+机构成员）已定，具体方式不影响第一版验证目标 |
| 首版终端/浏览器 | 电脑网页端；Chrome/Edge 近两年版本优先，移动端后做 | PRD 1 已定"第一版为电脑网页端" |
| 单场时长与录像大小 | 单项练习 ≤ 5 分钟、完整模拟 ≤ 20 分钟；录像存本地文件目录（不进数据库），单文件建议 ≤ 1GB，具体待技术验证 | PRD F05 明确不预设固定值、待验证 |
| 转写/反馈链路 | "提交 + 异步分析"模式，不追求实时；超时用预设弹幕降级 | PRD 7 已允许降级，延迟门槛待验证 |
| 商品/主题资料格式 | 第一版仅文本（可粘贴），图片/表格/PDF 导入后做 | F13 文件格式待确认，先跑通文本闭环 |
| 反馈"具体可信"验收 | 记"待样例打分"，第一次真实冒烟用 5–10 条样例由你打分定线 | 通用手册第十节默认评分法 |
| 个人录像留存 | 默认保存 90 天、用户可随时删除，删除后 30 天内清备份 | 参照其他项目数据留存默认；机构任务删除规则见必须问 4 |
| 部署位置 | 境内 | 涉音视频敏感数据，与隐私默认一致 |

## 已发现的矛盾（如有）
- 机构功能定位：PRD 将机构任务（F11）、机构内容管理（F13）标 P0 包含，同时 1.2 称"机构培训效率暂不作为首要成功标准"、2.2 排除"复杂机构场景编辑器"。→ 推荐裁决：机构只做最小闭环、不设机构效率量化验收，复杂编辑器排除。此点与必须问 3 一并确认，不另增问题。
