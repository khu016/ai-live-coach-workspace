# 第二阶段技术开发文档｜实时语音转写驱动动态弹幕

> 配套：`docs/PRD/AI主播陪练_PRD_v1.1.md`（唯一权威版本）、第一阶段技术开发文档、通用技术栈手册。
> 本文档覆盖阶段 2 的第二切片：以腾讯云实时语音识别（WebSocket）为主 ASR，实现「边说边转写 → 稳定转写触发动态弹幕 → 证据链 → 练后反馈」。不提前实现机构、镜头提醒、正式前端等其他能力。

## 一、阶段目标与范围

### 1.1 目标
在既有「个人主播纵向切片」之上，新增实时互动闭环：

```
浏览器麦克风 →（PCM 16k 直传）→ 本产品后端 →（转发）→ 腾讯云实时语音识别
                                    ↑ 返回临时/稳定转写
                    稳定转写落库 + 触发动态弹幕（LLM 生成 / 预设降级）
                    记录「发言→触发原因→弹幕→主播回应」证据链
```

练后反馈优先使用实时阶段已保存的**稳定转写**；实时转写缺失或不完整时，使用已保存的稳定文本与录像完成反馈（不阻塞、不伪造），**不启用讯飞离线转写**。

### 1.2 范围
- P0：浏览器实时音频流、腾讯云实时语音识别、临时/稳定转写区分、稳定转写触发动态弹幕、证据链、降级、练后反馈接证据链。
- 不做：讯飞离线兜底（后置，代码保留不接线）、机构功能、镜头提醒、正式前端。

## 二、已确认决策（2026-09-20 产品经理确认）

| 编号 | 决策 | 结论 |
| --- | --- | --- |
| R1 | 实时 ASR 供应商 | 腾讯云实时语音识别（WebSocket），第一版唯一主 ASR |
| R2 | 转写缺失兜底 | 用已保存稳定文本 + 录像完成反馈；讯飞离线转写后置，代码保留不接线 |
| R3 | 浏览器音频链路 | 浏览器 PCM 16kHz/16bit 单声道直传后端，后端不转码转发腾讯云 |
| R4 | 弹幕触发参数 | 最小间隔 5s、冷场判定 15s、生成超时 8s（对齐 PRD 8.1） |
| R5 | 动态弹幕依据 | 仅依据语音文本与互动事件，不依赖表情/眼神/手势/画面 |

## 三、统一 ASR 抽象层（换供应商不改业务）

新增 `backend/app/services/asr_base.py`，定义三块：

```text
ASREvent        # kind: partial(临时) | final(稳定)；text；start_sec/end_sec
ASRTranscript   # 离线转写结果（segments + full_text + provider），供以后兜底复用
ASRSession      # 实时会话接口：send_audio(pcm) / send_end() / receive_event() / close()
RealtimeASRProvider  # 工厂：open_session(**params) -> ASRSession
```

- `get_realtime_asr()` 按 `ASR_PROVIDER` 返回 `TencentRealtimeASR` 或 `MockRealtimeASR`。
- 业务层（实时会话编排、弹幕触发、反馈）只依赖 `ASRSession` / `ASREvent`，不 import 具体供应商。
- 讯飞 `XfyunASR.transcribe()` 保留为离线接口实现（`ASRTranscript`），当前不接线，后置启用时零改动业务层。

## 四、腾讯云实时语音识别适配器

新增 `backend/app/services/asr_tencent.py`。

- 端点：`wss://asr.cloud.tencent.com/asr/v2/{APPID}`，鉴权参数放 URL query。
- 签名（已按官方 SDK 核对）：`signStr = "asr.cloud.tencent.com/asr/v2/{appid}?{按 key 升序的 k=v&...}"`，`signature = Base64(HmacSHA1(SecretKey, signStr))`，拼 URL 前对 signature 做 URL 编码；`appid` 在路径中，其余参数排序后参与签名。
- 音频：`voice_format=1`（PCM 16kHz 16bit 单声道），分帧二进制发送；结束时发 `{"type":"end"}`。
- 结果：文本帧 JSON。本 appid/engine 不支持 `result_mod=1`（句子模式），实际走默认流式模式，`result.slice_type`：
  - `0` 一段话开始（忽略/打点）
  - `1` 识别中 → `ASREvent(kind="partial")`（临时，只推界面）
  - `2` 一段话结束 → `ASREvent(kind="final")`（稳定，落库 + 触发弹幕）
- 兼容句子模式：`sentences.sentence_list` 里 `sentence_type` 0=中间（临时）、1=最终（稳定）。
- `start_time/end_time` 为毫秒（累计时间轴），`voice_text_str` 为文本。
- 断线：会话内抛错 → 上层标记降级，从新音频继续，不伪造缺失转写。
- 跨境：请求出口必须为大陆境内，否则报 6001；上线部署必须境内（D7），不开启跨境流量。

## 五、临时转写 vs 稳定转写

| | 临时（partial, slice_type=1） | 稳定（final, slice_type=2） |
| --- | --- | --- |
| 来源 | 识别中，文本会持续变化 | 一句话结束，文本确定 |
| 用途 | 仅推给界面显示 + 提前准备 | 落库为确定转写、触发动态弹幕 |
| 证据 | 不作长期反馈证据 | 作反馈证据与弹幕触发依据 |

稳定片段落 `transcript_segments`；临时文本不落库（是否保存临时文本供排障，暂定为不保存，试点再定）。

## 六、动态弹幕触发引擎

新增 `backend/app/services/dynamic_bullets.py`。

- 输入：最近确定转写片段、直播类型/目标、已触发场景卡与历史弹幕、主播是否回应、可选主题/商品/脚本、冷场/重复/回避/冲突信号。
- 触发判定（确定性代码决定何时调模型）：防抖 + 最小间隔（5s）+ 语义去重 + 必考场景覆盖；不因临时字符变化触发。
- 弹幕类型：追问 / 质疑 / 普通互动 / 话题承接 / 冷场激活。
- LLM 生成：带 `trigger_type` 与触发依据；超时（8s）/非法输出 → 当前训练点预设弹幕降级并记录原因。
- 每条弹幕记录 `trigger_type` + 触发依据（哪个转写片段 / 哪个场景 / 冷场）。

## 七、证据链数据模型

- 新增 `transcript_segments`：`id / training_id / source(realtime) / start_sec / end_sec / text / is_final / word_list(JSON) / created_at`。
- `bullet_events` 增加：`trigger_type`（追问/质疑/普通互动/话题承接/冷场激活/预设）、`trigger_segment_id`（触发转写片段）、`trigger_reason`（触发依据文本）、`status`（shown/fallback/failed）、`display_at`、`response_segment_ids`（主播回应片段，JSON）。
- 回应区间：弹幕展示后，其后（窗口内）的稳定片段记为回应；确定性规则，非模型决定。
- 反馈输入：`transcript_segments`（按时间排序）+ `bullet_events`（含触发依据）+ 规则卡。

## 八、降级与异常

- 实时转写连接失败/断开：状态显示「实时识别暂不可用」，预设弹幕继续，记录断开/恢复时间。
- 弹幕生成超时/非法：预设弹幕降级，记录失败原因。
- 练后反馈：实时稳定转写缺失时，用已保存稳定文本 + 录像完成反馈，不伪造、不阻塞；录像始终可用。
- 密钥缺失：后端启动或会话建立时明确报错，不静默降级冒充真实。

## 十、分阶段实施

- **阶段 A**：统一 ASR 抽象 + 腾讯云适配器 + Mock 实时 + `websockets` 依赖 + 单测（签名/解析/映射）。
- **阶段 B**：后端 WebSocket 中继 + 会话编排 + `transcript_segments` 落库（临时只推、稳定落库）。
- **阶段 C**：动态弹幕触发引擎 + 证据链字段 + 回应链接 + 单测。
- **阶段 D**：前端 AudioWorklet 采集 PCM + 实时转写显示 + 动态弹幕 + 状态/降级。
- **阶段 E**：反馈接证据链 + 缺失兜底（已保存稳定文本 + 录像）+ 真实冒烟。

## 十一、测试与验收

### 单元测试（mock）
1. 腾讯适配器：`_signature()` 固定输入定断言、slice_type 0/1/2 映射、协议帧解析、断线抛错。
2. 会话编排：临时只推不落库、稳定才落库；断流降级。
3. 触发引擎：五类触发、最小间隔、去重、必考覆盖、超时/非法降级、回应链接。
4. 反馈：prompt 用转写片段 + 触发依据；解析器兼容。
5. 配置：密钥缺失报错；工厂返回正确实例。

### 真实冒烟（PRD 8.1，需真实腾讯云 Key + DeepSeek）
- ≥10 段真实语音：临时连续更新；稳定语句 ≤3s（P50/P95）。
- 动态弹幕 ≤5s 出现（P50/P95）；语义相关性人工复核。
- 断网/超时 8s 内预设降级。
- 密钥不在浏览器代码/接口响应/日志/测试。

### 浏览器照着点
创建练习 → 授权 → 直播页见实时转写（临时+稳定）与动态弹幕 → 说不同内容弹幕相关 → 断流见降级提示 → 结束反馈可跳片段、证据链完整。
