## 第二切片已确认决策（2026-09-20）
| 编号 | 结论 |
| --- | --- |
| R1 | 第一版只用腾讯云实时语音识别（WebSocket）为主 ASR |
| R2 | 腾讯云转写缺失时用已保存稳定文本 + 录像完成反馈；讯飞离线转写后置（代码保留不接线） |
| R3 | 浏览器 PCM 16kHz/16bit 单声道直传后端，后端不转码转发腾讯云 |
| R4 | 弹幕最小间隔 5s、冷场判定 15s、生成超时 8s |
| R5 | 动态弹幕仅依据语音文本与互动事件，不用表情/眼神/手势/画面 |
| R6 | 每场只选 1–2 个必考场景（不每场全量），选在必考池内轮换、不跨类型 |
| R7 | 新建练习按练习 ID 确定性轮换必考题；重练继承原练习必考场景 |
| R8 | 必考与 LLM 动态弹幕穿插：一场最多连续 1 条必考弹幕，多场累计覆盖场景池 |
| R9 | 默认“普通活跃直播间”密度：所有弹幕平均 3–6 秒一条，关键发言后最多 2–3 条短组合 |
| R10 | 刁难弹幕每 20–40 秒最多一条；无关/路人/噪声不要求回应、不参与评分 |
| R11 | 环境弹幕主要从内容库抽取，相关追问/话题承接可调用 AI；统一调度避免环境定时与语音触发重复发射 |
