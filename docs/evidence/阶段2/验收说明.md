## 三、产品经理照着点（当前无 Key 时，可验证到"转写→反馈失败"这一步）

1. 打开 http://127.0.0.1:8001/
2. 选直播类型、填训练目标（可不填主题/商品），点"开始练习"。
3. 弹窗要摄像头/麦克风：先点"拒绝"，应看到可操作提示（不是假装录制）。
4. 重新授权后进入模拟直播：能看到自己画面，弹幕按时间出现（含"预设关键问题"）。
5. 点"结束练习"，等待：录像保存成功、进入转写；因未接 Key，反馈走到"分析失败"（这是如实状态）。
6. 接 Key 后重复第 2–5 步，能看到带时间点的反馈、跳片段、重练、对比。
